Commands

Commands

Guide

Commands are typed into the chat window and let you change the world directly. They need cheats enabled, which you set when creating a world, or can switch on temporarily in a single-player world by opening it to LAN. On a server you need operator permission.

Target Selectors
Most commands accept a shorthand for who or what they apply to.
@p: The nearest player.
@a: Every player.
@r: A random player.
@e: Every entity, mobs and items included.
@s: Whoever ran the command, which is usually you.
Selectors take filters in square brackets, so @e[type=creeper,distance=..20] means every creeper within twenty blocks.

Coordinates
Absolute coordinates are plain numbers: 100 64 -200.
A tilde means relative to your position, so ~ ~5 ~ is five blocks above you.
A caret means relative to the direction you are facing, which is how you place something in front of yourself regardless of heading.

Everyday Commands
/gamemode creative, survival, adventure or spectator.
/give @s diamond_pickaxe 1 places an item straight into your inventory.
/tp moves you to coordinates or to another player.
/time set day or night, and /weather clear, rain or thunder.
/difficulty peaceful through hard. Peaceful removes every hostile mob currently loaded.
/effect give @s minecraft:night_vision 600 grants an effect for a set time.
/kill @e[type=item] clears dropped items, which is a quick way to tidy lag.
/seed prints the world seed, and /locate finds the nearest structure of a given type.
/spawnpoint and /setworldspawn control where players appear.

Game Rules
/gamerule changes how the world behaves, and these are the ones people actually use.
keepInventory true: You keep your items when you die.
doDaylightCycle false: Freezes the time of day.
mobGriefing false: Stops creepers destroying blocks and endermen picking them up.
doFireTick false: Fire stops spreading.
randomTickSpeed: Controls how fast crops grow. Raising it far above the default of 3 will cripple performance.

Building Commands
/setblock places a single block at given coordinates.
/fill fills an entire region, which is how large flat areas get cleared instantly.
/clone copies a region from one place to another, useful for duplicating a build.
/summon spawns any entity, with optional data to configure it.

Command Blocks
Command blocks cannot be crafted. You obtain one with /give @s command_block, and only in creative mode. They run a stored command when powered, and chained together they are how adventure maps and minigames are built.

A Word of Warning
In Bedrock Edition, enabling cheats disables achievements for that world permanently; Java Edition advancements are unaffected. Commands like /fill across a huge region can also freeze the game while it works. Test on a copy of your world before running anything sweeping.
